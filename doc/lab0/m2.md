##  进程表

| 进程 | state | parent | pagetable | sz | ofile[0..2] | 备注 |
|---|---|---|---|---|---|---|
| init (pid=1) | SLEEPING | 0 (无父) | PGT_init | ? | 均→console file | 在 `wait()` 上 sleep（chan=init 自身地址） |
| sh (pid=2) | SLEEPING | init | PGT_sh | ? | 均→console file | 在 `wait()` 上 sleep（chan=sh 自身地址） |
| echo (pid=3) | **RUNNING** | sh | PGT_echo(新) | **0x4000** | 均→console file | 正运行在当前 hart；`trapframe->epc=0x7a`，`sp=0x3ff8 区` |

- 三个进程的 `ofile[0]`、`ofile[1]`、`ofile[2]` 都指向**同一个** `struct file`（console 设备）

## echo 进程页表


exec 后，`sz=0x4000`：

```text
VA 区间                    内容             PTE 权限位               来源
──────────────────────────────────────────────────────────────────────
0x0000_0000 – 0x0000_1000   text/代码       V|R|X|U  (RX)           LOAD#1 uvmalloc(PTE_X)
0x0000_1000 – 0x0000_2000   data/bss        V|R|W|U  (RW)           LOAD#2 uvmalloc(PTE_W)
0x0000_2000 – 0x0000_3000   guard page      V|R|W    (无U)          uvmclear 清 PTE_U
0x0000_3000 – 0x0000_4000   user stack      V|R|W|U  (RW)           uvmalloc(PTE_W)
                            (栈顶 sp=0x4000, 栈底 0x3000)
──────────────────────────────────────────────────────────────────────
   （中间大片未映射，堆区在 sz=0x4000 之上按需增长）
──────────────────────────────────────────────────────────────────────
0x3FFF_FE000–0x3FFF_FF000   TRAPFRAME       V|R|W    (无U)           proc_pagetable
0x3FFF_FF000–0x4000_000000  TRAMPOLINE      V|R|X    (无U)           proc_pagetable
```

`MAXVA=1<<38=0x4000_000000`，`TRAMPOLINE=MAXVA-0x1000=0x3FFF_FF000`，`TRAPFRAME=TRAMPOLINE-0x1000=0x3FFF_FE000`。

- **guard page**：`exec` 里 `uvmclear`（`kernel/exec.c:95`）清掉该页 PTE_U，栈向下溢出时触发用户态访问异常。
- 参数栈布局（`kernel/exec.c:99-124`）：栈顶向下依次压入 `"echo\0"`、`"hi\0"`、`argv[]={"echo","hi",0}`；`trapframe->a1=argv` 数组地址，`a0=argc=2`（作为 `main(argc,argv)` 前两参）。

> **堆此刻为空** echo 不用 `malloc/sbrk`，因此**不存在堆区映射**。

## 文件表

console 设备文件的建立链（`user/init.c:19-24` → `kernel/sysfile.c:395-412` → `kernel/sysfile.c:309-376`）：

```text
echo->ofile[1] (fd=1)                    
     │                                  
     ▼                                   
 struct file (ftable.file[0])            
   type   = FD_DEVICE                    
   ref    = 9    ◄── init×3 + sh×3 + echo×3 各 filedup 一次
   readable = 1, writable = 1            
   major  = 1 ───────────────────────────►  devsw[1].write = consolewrite  
   ip ──────────► struct inode (itable.inode[k])
                   dev=1, inum=k, ref=1,
                   type=T_DEVICE, major=1(CONSOLE), minor=0,
                   nlink=1, size=0
```



- `mknod("console",CONSOLE,0)` 建 inode（T_DEVICE, major=1），随后 `iunlockput` 把 inode ref 归零；
- `open` 时 `namei`→`iget` 使 inode `ref=1`，`f->ip=ip` ， **inode ref=1**；
- 同一 `struct file` 被 `dup(0)` 两次（init，ref 1→3），随后 `fork`（sh，3→6）、再 `fork`（echo，6→**9**）。**file ref=9**）。

## read 阻塞等待，键盘中断唤醒

```text
[U] shell: gets() → read(0, buf, 1)       US
        │  usys.S: li a7,5; ecall
        ▼  ═══ 陷入: scause=8, sepc=ecall后一指令, SPP=0 ═══
[S] uservec (kernel/trampoline.S:22-98)   US,satp=用户页表
        │  保存全部用户寄存器→p->trapframe; 切 sp=KS(shell); satp=内核页表
        ▼
[S] usertrap (kernel/trap.c:38)           KS(shell), stvec←kernelvec
        │  scause==8 → epc+=4 → intr_on → syscall()
        ▼
[S] syscall (kernel/syscall.c:137)  a7=5 → sys_read()
        ▼
[S] sys_read → fileread → FD_DEVICE → devsw[1].read = consoleread   ⛨spin:cons.lock
        │  缓冲空(cons.r==cons.w) → sleep_prepare(&cons.r) → release锁 → sleep()
        │   sleep(): acquire p->lock → state=SLEEPING → sched() → swtch 
        ▼
[S] scheduler()  SCH,⛨spin:p->lock(直到进程回来才释放)
        │  无 RUNNABLE 进程可跑 → wfi（hart 空闲等待中断）
        ▼
  （敲 'e','c','h','o',' ','h','i', 最后回车；每敲一个键触发一次外部中断）
        ▼
[S] UART 外部中断:  KS(其他的进程，被中断打断的), scause=0x8000000000000009 → uservec → usertrap
        │  usertrap→devintr()(kernel/trap.c:187) → plic_claim()=UART0_IRQ(10)
        │  → uartintr()(kernel/uart.c:138) → consoleintr(c)(kernel/console.c:147)   ⛨spin:cons.lock
        │      回显该字符(uartputc_sync); 写入 cons.buf;
        │      遇 '\n' → cons.w=cons.e → wakeup(&cons.r)  → shell: SLEEPING→RUNNABLE
        ▼
[S] 中断返回 userret ──[sret]──► 回到被中断的上下文
```

> 键盘字符是“逐字符”驱动的。`consoleintr` 在**中断上下文**里持有 `cons.lock` 自旋锁，把字符丢进环形缓冲 `cons.buf`，只有收到 `\n`/`^D` 才 `wakeup(&cons.r)`。shell 的 `read(0,...,1)` 由 `consoleread` 实现：整行到达前会一直 sleep（`kernel/console.c:88-138`）。

## shell 被唤醒，读入 `"echo hi\n"`

```text
[S] scheduler 选中 shell → swtch → sched() 返回 → sleep() 返回
        │  consoleread 重新 acquire cons.lock，把 "echo hi\n" 逐字节 copyout 到用户 buf
        ▼  ═══ userret ──[sret]──►
[U] shell: US, read 返回; getcmd 返回 0; 解析 "echo hi" → execcmd{argv=["echo","hi"]}
        ▼
[U] shell: fork1() → fork()  usys.S a7=1; ecall
        ▼  ═══ 陷入 ═══
[S] uservec → usertrap → syscall → sys_fork → kfork()(kernel/proc.c:259)  US->KS(shell),  ⛨spin:pid_lock,⛨p->lock,⛨wait_lock
        │  allocproc: 新建子进程(pid=3), 拷贝页表(uvmcopy), 拷贝 trapframe
        │  子进程 trapframe->a0=0; ofile filedup×3; parent=shell; state=RUNNABLE

        ▼  ═══ userret ──[sret]──►
[U] shell: fork 返回（≠0）→ 走父分支 wait(0)
```

## 子进程 exec("echo")

```text
[U] 子进程 首次被调度 → forkret → prepare_return → userret ──[sret]──►
[U] 子进程: fork 返回 0 → runcmd → EXEC 分支 → exec("echo", argv)   a7=7; ecall
        ▼  ═══ 陷入 ═══
[S] uservec → usertrap → syscall → sys_exec(kernel/sysfile.c:440)
        │  逐层 fetchargv(内核 kalloc 缓冲) → kexec(path, argv)
        ▼
[S] kexec(kernel/exec.c:28)  KS(echo)  ⛨slp:ip->lock(逐段); ⛨spin:itable.lock 等
        │  namei("echo")→ilock→读 ELF 头→校验 magic→proc_pagetable(新页表)
        │  逐 LOAD 段 uvmalloc + loadseg 载入 text/data
        │  分配 guard+user stack 两页, uvmclear(guard)
        │  压栈 argv 字符串与指针数组; trapframe->epc=elf.entry(0x7a); sp=栈顶
        │  提交: p->pagetable=新页表; p->sz=0x4000; proc_freepagetable(旧页表)
        │  safestrcpy(p->name,"echo")
        │  返回 argc=2
        ▼
[S] syscall: p->trapframe->a0 = 2
        ▼
[S] usertrap 尾部: killed?→no; which_dev==0(非中断)不 yield; prepare_return()
        │  intr_off; stvec←uservec; 填 kernel_satp/sp/trap/hartid; sstatus SPP=0,SPIE=1
        ▼  ═══ userret ──[sret]──►
[U] echo: 首条指令 = ulib.c:start() (elf.entry=0x7a)  ★材料二的截面时刻
```
